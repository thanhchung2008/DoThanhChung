
# GreenField – Đặt sân bóng mini.

Một website đặt sân bóng mini (sân 5, sân 7) thường được thiết kế theo hướng *trực quan, dễ thao tác và tối ưu* **cho cả người chơi (người tìm sân) lẫn chủ sân (người quản lý).**
|Thư mục | Nội dung|
|:---:|:---:|
|docs | Tài liệu bàn giao|
|data | Bảng tính đặt sân|
|logs | Log truy cập website.|
